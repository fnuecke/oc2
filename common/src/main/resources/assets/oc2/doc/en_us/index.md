# The Computerists Handbook
Hello, greetings, welcome! If you've come here, you either stumbled in by accident, are interested in [building your first computer](systems/index.md), or maybe you are looking for information on a particular [block](block/index.md) or [item](item/index.md)?

## Overview
[Computers](block/computer.md) offer a variety of uses, from recreational to large-scale, highly customizable automation of other machines and devices.

At the heart of each computer lies its processor and accompanying operating system. The [RISC-V processor](item/cpu_riscv.md) runs OpenOS II or Linux, the [Z80 processor](item/cpu_z80.md) runs CP/M. Programs control devices such as the [redstone interface block](block/redstone_interface.md) through the high-level API ([HLAPI](hlapi.md)) or the mid-level API ([MLAPI](mlapi.md)). The [basics](basics.md) entry explains these concepts.

## Getting Started
If you just want to get running quickly, read the [getting started guide](systems/index.md).
