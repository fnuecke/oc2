# RISC-V Processor
![The part that does the thinking.](item:oc2:cpu_riscv)

The processor is what a [computer](../block/computer.md) or [robot](robot.md) actually computes with. Without one in its processor slot, a machine will not start.

This is the 64-bit RISC-V processor. It runs [OpenOS II](../systems/openos2.md) and [Linux](../systems/linux.md). Crafting it together with blank flash memory or a hard drive writes the firmware or an operating system to them, see the guides for details.

Also see the [Z80 processor](cpu_z80.md).
