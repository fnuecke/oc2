# Inventory Operations Module
![What's yours is mine](item:oc2:inventory_operations_module)

The inventory operations module provides to [robots](robot.md) the ability to insert and extract items from inventories in the world. This supports block and entity inventories, as well as container items in the robot's inventory, such as shulker boxes. Without an inventory present, given sufficient space, it allows dropping or taking items into and from the world.

## API
Programs control the module through the `inventory_operations` device. See the [inventory operations device](../device/inventory_operations.md) reference for its methods.
